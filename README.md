**Multi-Sheet Sales Performance Dashboard**

** Project Overview**
This project is an interactive multi-sheet Excel dashboard created to analyze sales performance and business insights.  
The dashboard helps track sales, profit, category performance, regional trends, and salesperson performance using dynamic charts and visualizations.

---

** Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Conditional Formatting

---

** Dashboard Features**
- Interactive multi-sheet dashboard
- Sales and profit analysis
- Category-wise performance tracking
- Regional sales insights
- Salesperson performance comparison
- KPI metrics visualization
- Dynamic filtering using slicers

---

 
---

 Key Insights
- Identified top-performing product categories
- Compared sales across different states
- Analyzed monthly sales trends
- Evaluated salesperson performance
- Tracked profit margin and total sales KPIs
